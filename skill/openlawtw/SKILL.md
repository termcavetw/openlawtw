# openlawtw｜臺灣建築法規查詢

這個 skill 讓你在回答臺灣建築、都市計畫、土地使用相關法規問題時，**先查 openlawtw 資料庫裡的現行條文與函釋，再回答**，不憑記憶。

資料庫內容：中央與 22 縣市共 1,045 部建築、都市計畫、土地開發相關法規（逐條切好），以及 8,700 多則內政部國土管理署（原營建署）函釋，每週和官方同步。

## 先看有沒有 openlawtw MCP

如果你的工具清單裡已經有 openlawtw MCP 的工具（名稱是 `find_law`、`get_article`、`search_articles`、`search_rulings`、`get_ruling`、`check_conflicts`、`list_articles`、`search_documents`、`get_document`、`data_info`，前面可能帶有 openlawtw 之類的前綴），**直接用這些工具，不用跑下面的腳本**。兩者資料和警告一致，MCP 比較快。下面的鐵則、流程與回答格式照樣適用。

沒有 MCP 工具時，才用本 skill 附的腳本。

## 鐵則

1. **條號、條文內容、函釋字號一律查過才寫。** 就算你很確定也要查，因為法規常修正，記憶裡的版本可能已經過時。
2. **引用要能追溯：** 寫出法規全名＋條號，引用關鍵原文，附上腳本給的連結。函釋要寫字號和日期。
3. **查不到就說查不到。** 不要補一個看起來合理的條號，也不要捏造函釋。
4. **回答前檢查效力：** 留意腳本印出的「施行日註記」「狀態」、條文裡的（刪除），以及「函告無效」之類的註記，有的話要明白告訴使用者。
5. **函釋的效力：** 函釋旁出現「⚠ 已由…停止適用」時，這則**不能再當依據**，改引那則新的函釋並說明。出現「⚠ …於 … 修正，晚於本函釋」時，先比對函釋引用的條文和現行條文是否一致；不一致就說明這則函釋是針對修正前的條文，可能已不完全適用。（修正日期取自中央法規的沿革；地方法規通常沒有沿革，不會有這個提醒。）
6. **例外與但書要講出來：** `article` 會列出【例外與但書】（但書、除外、不受限制、不適用、免計／免設、另有規定）。回答時，凡是會改變結論的例外都要明白寫出來，例如「原則上…，但…者不在此限」，並提醒使用者確認個案是否符合例外條件。不要只講原則。
7. **條文引用了已刪除的條文：** 看到「⚠ 本條引用的『…』已刪除」時，要告訴使用者該條引用的規定已不存在，請查證現行適用規定（例如改依哪部規範），不要把被刪除的條文當成有效規定。
8. **地點很重要：** 問題涉及特定縣市時，中央法規查完還要查該縣市的自治條例或規定（`--region 桃園市`）。地方規定可能比中央嚴格，也可能放寬。
9. **網路資料只能當線索：** 條文與函釋以 openlawtw 查到的為準。網路文章、新聞、論壇的說法要拿來跟條文核對；不一致時以條文為準，並明白告訴使用者網路說法哪裡錯（例如漏了但書、把地方規定當成中央規定）。
10. **本庫沒有的才上網查：** 土管要點、其他機關或縣市政府函釋、法院判決、最新修法動態，可以上網查，但優先找政府官方網站（.gov.tw），引用時註明來源網站與日期，並說明這部分不是來自 openlawtw。
11. **來源順位：** 效力由高到低為 (1) 法律、法規命令與技術規範的條文；(2) 內政部國土管理署（原營建署）函釋，含正式發文的研商會議紀錄；(3) 縣市主管建築機關的函釋、建照工作手冊、審查或複核決議（只適用該縣市）；(4) 建築師公會、學會的講座簡報與實務整理；(5) 一般網路文章、新聞、論壇。回答時每個依據都標明屬於哪一級；較低級的說法和較高級的不一致時，以較高級為準並說明差在哪。第 3 級只能用在該縣市的案子；第 4、5 級只能當實務參考或線索，不能當法源，也不能寫成「依規定」。網路上找到的函釋、會議紀錄、簡報，要找到原文件（發文機關、字號、日期）才能引用；找不到原文就說明「未見原文，僅供參考」。
12. **必要時用官方網站核對：** 遇到下列情況，要打開腳本附的「官方來源」連結（全國法規資料庫、縣市法規網、國土署函釋頁面），核對關鍵條文的內容與最新修正日是否一致：(a) 答案會用在擬函、送審、回覆業主等正式用途；(b) 使用者問到最近有沒有修正；(c) `OL info` 顯示最近同步已超過 7 天。只拿官方網站核對，不拿一般網路文章核對。對不上時以官方網站為準，告訴使用者 openlawtw 可能尚未同步，並建議回報給 openlawtw。連不到官方網站時，說明未能核對。
13. 你提供的是法規查詢與整理，**不是**主管機關的認定。個案適用時，提醒使用者以主管建築機關的審查為準。

如果環境裡找不到這支腳本，先下載（GitHub 連不到時自動改用 CDN 鏡像）：


| 資料版本與同步時間 | `OL info` |

- 法規可以用全名、ID（如 `D0070115`）或常用簡稱：建技、設計施工編、構造編、設備編、變使、室裝、公安、危老、危老獎勵、危老細則、都更條例、非都管制、無障礙規範、特登、毗連擴廠……
- `find-law 危老`、`find-law 都更`、`find-law 建技` 會列出整個系列的法規（例如危老條例、容積獎勵辦法、施行細則、結構評估辦法），不確定要查哪一部時先用這個。
- `article` 會印出法規的「制定／訂定日期」，計算「施行後第幾年」這類期限時用它當起算點，並說明實際起算日以條文規定為準。
- 條文有附表、附圖或補充圖例時，`article` 會印出「圖表附件」和官方檔案連結。回答涉及附表內容（例如使用類組定義）時，要附上連結，請使用者打開確認。
- 條號可以寫 `107`、`164-1`、`164之1`、`第一百零七條`。
- `search` 預設只搜中央法規；`--region 全部` 搜所有縣市（第一次會下載約 22MB，之後有快取）。全部關鍵字都沒對到時，可以加 `--any`，或改用同義詞再查（例如「昇降機」和「電梯」、「容積」和「樓地板面積」）。

## 建議流程

1. **拆問題：** 這題牽涉哪些法規？基地在哪個縣市？是都市計畫區還是非都市土地？
2. **定位條文：** 知道法規就直接 `article`；不確定在哪一條就 `search`，再用 `article` 讀全文。條文裡提到「前條」「第 X 條」或其他法規時，也要追查下去。
3. **查函釋：** 對關鍵條文跑 `rulings --law … --article …`，挑日期較新、和案情最接近的幾則，用 `ruling <id>` 讀全文再引用。跳過標示已停止適用的函釋。函釋前後矛盾時，以日期較新的為主，並說明有這個差異。
4. **檢查例外：** 讀【例外與但書】，判斷使用者的情況是落在原則還是例外。需要時用 `conflicts` 確認相關條文和函釋有沒有失效的問題。
5. **查地方規定：** 用 `search … --region <縣市>` 或 `find-law <縣市名> <關鍵字>`。
6. **回答：** 先給結論，再列依據。

## 回答格式

先用一兩句話給結論，接著列依據：

> **依據**
> - 建築技術規則建築設計施工編第 107 條第 1 款第 3 目：「出入口應為具有一小時以上防火時效之防火門。除開向特別安全梯外，限設一處，且不得直接連接居室。」（[連結](https://openlawtw.vercel.app/laws/D0070115.html#a-107)）
> - 內政部營建署 108.03.20 營署建管字第 1081051682 號函：機間在避難層的出入口仍只能設一處……（[連結](https://www.nlma.gov.tw/ch/titlelist/interpcomp/13672)）
>
> 資料：openlawtw（同步於 2026-11-10）。個案適用以主管建築機關審查為準。

- 原文只引用關鍵的那一句或那一款，不要整條貼上，除非使用者要看全文。
- 同步日期從 `OL info` 取得；使用者問的事情可能在那之後有變動時，要特別提醒。

## 限制

- **原文文件：** 建築物無障礙設施設計規範、建築物耐震設計規範及解說、綠化／保水／節能／雨水貯留／雜排水回收等技術規範、綠建材設計技術規範，以及部分縣市的造價標準表、裁罰基準等共 38 份，沒有逐條條文，`article` 讀不到，要用 `doc-search`／`doc`。無障礙尺寸（坡道、扶手、廁所、停車位、昇降機）一定要查無障礙規範的節號，不要憑記憶。引用寫「建築物無障礙設施設計規範 805.1」並附 PDF 頁碼與連結；文字是從 PDF 擷取的，圖、表、公式以原檔為準。
- 條文的附表、附圖多半是 PDF（腳本會印出「圖表附件」）。部分附表已自行抽出文字（`article` 會在附件旁標示「已抽出文字」，用 `doc` 讀）；其餘內容沒有收錄，請使用者打開官方連結。
- 「例外與但書」「停止適用」「引用已刪除條文」都是用句型自動比對的，大多數正確，但可能漏抓或誤判；引用前要讀原文確認。
- 函釋目前只收國土署的函釋彙編，不包括各縣市政府自己的函釋，也不包括經濟部（工業、工廠、擴廠）、農業部（農舍、農業設施）、消防署等其他機關的函釋。查到 0 則時要說明可能是不在收錄範圍，而不是沒有函釋。
- **各都市計畫書和土地使用分區管制要點沒有收錄。** 開挖率、建蔽率、容積率、退縮、停車獎勵等常寫在個別都市計畫的土管要點裡，查不到時要明說「這通常規定在該都市計畫的土管要點，本庫未收」，請使用者查該都市計畫書，不要拿其他法規的數字代替。
- 有些函釋只有標題、沒有全文，腳本會說明；引用時只能引標題與字號。
- 網路連不到資料來源時，腳本會改用 GitHub 鏡像，再不行就用本機快取。都失敗的話，請直接告訴使用者無法查詢，**不要改憑記憶回答**。如果有 openlawtw 專案的本機副本，可以設定 `OPENLAW_DATA=<專案路徑>` 離線使用。
