# openlawtw｜臺灣建築法規查詢

這個 skill 讓你在回答臺灣建築、都市計畫、土地使用相關法規問題時，**先查 openlawtw 資料庫裡的現行條文與函釋，再回答**，不憑記憶。

資料庫內容：1,000 部以上的中央與 22 縣市法規（逐條切好），以及 9,000 多則內政部國土管理署（原營建署）函釋，每週和官方同步。

## 鐵則

1. **條號、條文內容、函釋字號一律查過才寫。** 就算你很確定也要查，因為法規常修正，記憶裡的版本可能已經過時。
2. **引用要能追溯：** 寫出法規全名＋條號，引用關鍵原文，附上腳本給的連結。函釋要寫字號和日期。
3. **查不到就說查不到。** 不要補一個看起來合理的條號，也不要捏造函釋。
4. **回答前檢查效力：** 留意腳本印出的「施行日註記」「狀態」、條文裡的（刪除），以及「函告無效」之類的註記，有的話要明白告訴使用者。
5. **舊函釋要對照現行條文：** `article` 會印出「本條最近修正」日期；函釋如果早於它所涉條文的最近修正日，`rulings`／`ruling` 會印出 ⚠。看到 ⚠ 時，先比對函釋引用的條文內容和現行條文是否一致。不一致的話，要說明這則函釋是針對修正前的條文，可能已不完全適用，並優先採用修正後的函釋。（修正日期取自中央法規的沿革；地方法規通常沒有沿革，不會有這個提醒。）
6. **地點很重要：** 問題涉及特定縣市時，中央法規查完還要查該縣市的自治條例或規定（`--region 桃園市`）。地方規定可能比中央嚴格，也可能放寬。
7. 你提供的是法規查詢與整理，**不是**主管機關的認定。個案適用時，提醒使用者以主管建築機關的審查為準。

## 工具

腳本在本 skill 資料夾的 `scripts/openlaw.py`，只用 Python 標準庫。

如果環境裡找不到這支腳本，先下載（GitHub 連不到時自動改用 CDN 鏡像）：

```bash
curl -sfL https://raw.githubusercontent.com/termcavetw/openlawtw/main/skill/openlawtw/scripts/openlaw.py -o /tmp/openlaw.py \
  || curl -sfL https://cdn.jsdelivr.net/gh/termcavetw/openlawtw@main/skill/openlawtw/scripts/openlaw.py -o /tmp/openlaw.py
```

以下用 `OL` 代表 `python3 <腳本路徑>`。

| 要做的事 | 指令 |
|---|---|
| 找法規、確認全名與 ID | `OL find-law 變使`、`OL find-law 桃園市 建築管理`（多個詞要全部符合；寫縣市名就只找該縣市） |
| 讀條文（可一次多條） | `OL article 設計施工編 107 108` |
| 看整部法規的章節目錄 | `OL toc 建築法` |
| 全文搜尋條文（關鍵字全部符合） | `OL search 緊急用昇降機 避難層` |
| 限定縣市或法規 | `OL search 停車 --region 中央,桃園市`、`OL search 開挖率 --law 設計施工編` |
| 找某一條的函釋 | `OL rulings --law 設計施工編 --article 107` |
| 用關鍵字找函釋 | `OL rulings 農舍 解除套繪` |
| 讀函釋全文 | `OL ruling 13672` |
| 資料版本與同步時間 | `OL info` |

- 法規可以用全名、ID（如 `D0070115`）或常用簡稱：建技、設計施工編、構造編、設備編、變使、室裝、公安、危老、危老獎勵、危老細則、都更條例、非都管制、無障礙規範、特登、毗連擴廠……
- `find-law 危老`、`find-law 都更`、`find-law 建技` 會列出整個系列的法規（例如危老條例、容積獎勵辦法、施行細則、結構評估辦法），不確定要查哪一部時先用這個。
- `article` 會印出法規的「制定／訂定日期」，計算「施行後第幾年」這類期限時用它當起算點，並說明實際起算日以條文規定為準。
- 條文有附表、附圖或補充圖例時，`article` 會印出「圖表附件」和官方檔案連結。回答涉及附表內容（例如使用類組定義）時，要附上連結，請使用者打開確認。
- 條號可以寫 `107`、`164-1`、`164之1`、`第一百零七條`。
- `search` 預設只搜中央法規；`--region 全部` 搜所有縣市（第一次會下載約 22MB，之後有快取）。全部關鍵字都沒對到時，可以加 `--any`，或改用同義詞再查（例如「昇降機」和「電梯」、「容積」和「樓地板面積」）。

## 建議流程

1. **拆問題：** 這題牽涉哪些法規？基地在哪個縣市？是都市計畫區還是非都市土地？
2. **定位條文：** 知道法規就直接 `article`；不確定在哪一條就 `search`，再用 `article` 讀全文。條文裡提到「前條」「第 X 條」或其他法規時，也要追查下去。
3. **查函釋：** 對關鍵條文跑 `rulings --law … --article …`，挑日期較新、和案情最接近的幾則，用 `ruling <id>` 讀全文再引用。函釋前後矛盾時，以日期較新的為主，並說明有這個差異。
4. **查地方規定：** 用 `search … --region <縣市>` 或 `find-law <縣市名> <關鍵字>`。
5. **回答：** 先給結論，再列依據。

## 回答格式

先用一兩句話給結論，接著列依據：

> **依據**
> - 建築技術規則建築設計施工編第 107 條第 1 款第 3 目：「出入口應為具有一小時以上防火時效之防火門。除開向特別安全梯外，限設一處，且不得直接連接居室。」（[連結](https://openlawtw.vercel.app/laws/D0070115.html#a-107)）
> - 內政部營建署 108.03.20 營署建管字第 1081051682 號函：機間在避難層的出入口仍只能設一處……（[連結](https://www.nlma.gov.tw/ch/titlelist/interpcomp/13672)）
>
> 資料：openlawtw（同步於 2026-11-10）。個案適用以主管建築機關審查為準。

- 原文只引用關鍵的那一句或那一款，不要整條貼上，除非使用者要看全文。
- 同步日期從 `OL info` 取得；使用者問的事情可能在那之後有變動時，要特別提醒。

## 限制

- 條文的附表、附圖多半是 PDF（腳本會印出「圖表附件」），內容沒有收錄在文字裡。遇到要看附表的問題，請使用者打開官方連結。
- 函釋目前只收國土署的函釋彙編，不包括各縣市政府自己的函釋，也不包括經濟部（工業、工廠、擴廠）、農業部（農舍、農業設施）、消防署等其他機關的函釋。查到 0 則時要說明可能是不在收錄範圍，而不是沒有函釋。
- **各都市計畫書和土地使用分區管制要點沒有收錄。** 開挖率、建蔽率、容積率、退縮、停車獎勵等常寫在個別都市計畫的土管要點裡，查不到時要明說「這通常規定在該都市計畫的土管要點，本庫未收」，請使用者查該都市計畫書，不要拿其他法規的數字代替。
- 有些函釋只有標題、沒有全文，腳本會說明；引用時只能引標題與字號。
- 網路連不到資料來源時，腳本會改用 GitHub 鏡像，再不行就用本機快取。都失敗的話，請直接告訴使用者無法查詢，**不要改憑記憶回答**。如果有 openlawtw 專案的本機副本，可以設定 `OPENLAW_DATA=<專案路徑>` 離線使用。
