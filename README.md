## v0.14.0 法規宇宙

頁首「法規宇宙」或側欄「法源 → 探索法規宇宙」可開啟；也支援 `/#view=universe`。626 部法規、290 筆法源關係依原資料繪製；函釋圖層另載入 9,054 筆節點、1,670 筆互引及 8,545 筆去重後的函釋引法連線（不是條文關聯數）。

- 點節點聚焦已收錄關係；《建築法》可逐層展開 116 部下游法規。直接連結的原文依據可在側面展開核對。
- 拖曳平移、滾輪／雙指縮放；鍵盤方向鍵移動、加減鍵縮放、Home 回全圖，搜尋也可選節點。
- 全台／縣市篩選、閱讀原文、播放導覽、純圖模式、PNG 匯出。手機提供可收合詳情。
- 關係布局於 build 時計算，畫面靜止時不持續運算。初始開啟不預抓宇宙資料；查看後依 PWA 機制快取。單檔 HTML 內嵌完整圖層。
- 位置、距離、節點大小不代表法規位階、適用性或法律重要程度；沒有連線不代表無關。函釋互引不表示沿用或取代。

本版型別檢查、建置、資料及圖模型檢查已通過；受預覽環境權限限制，v0.14 新介面未完成瀏覽器及真機互動實測。部署前請依 VALIDATION.md 的待測清單確認。

v0.13.1：桌機函釋並讀欄支援拖曳分隔線調整寬度並記住設定；雙擊或 Enter 恢復預設，方向鍵微調。函釋標題區限制高度，保留原文閱讀空間。

以條文閱讀為主，目錄預設收合。桌機條號與函釋按鈕放在正文左側，手機放在正文上方同一列。選擇縣市後，可查中央與地方規定、官方原文和資源入口。

## v0.13.1 工作區入口

根網址與 PWA 預設進入工作區。第一次造訪顯示搜尋、常用法規與收藏；再次開啟回到本機上次閱讀法規及記錄的條文位置。明示分享條號優先，重新整理則嘗試恢復本機閱讀位置。瀏覽器封鎖或清除儲存時會回到工作區起始畫面。

Logo 聚焦搜尋，不再跳介紹頁。切換縣市只更新搜尋範圍，保留目前條文。「關於」主動開啟介紹頁，`#view=about` 是介紹入口；舊 `#region=縣市` 改進入該範圍的工作區。

## 維護與資料貢獻

本專案由維護者依可用時間更新，未完整收錄全台建築相關規定，不承諾補齊或回覆時程。

資料缺漏或勘誤，請附**官方來源網址**送 Pull Request，或寄至 [termcavetw@gmail.com](mailto:termcavetw@gmail.com)。不提供個別支援、個案法規適用判斷或法律諮詢；來信不保證逐一回覆。

資料 PR 僅接受可追溯的官方原文、官方附件及來源／日期校正。不收貢獻者自行撰寫的法規解釋、註解或適用結論；主管機關正式函釋屬可收錄的官方資料。俗稱、搜尋詞彙及分類須與原文明確分離，詳見 [CONTRIBUTING.md](CONTRIBUTING.md)。程式修正亦可透過 PR 提交。

本專案不以 Issues 提供客服；若儲存庫未開啟 Issues，仍可使用上述管道。公開 PR 請勿附個資、未公開案件文件或帳號憑證。

## 閱讀與查找

- 桌機函釋在左側並讀；手機保留正文全寬，頂列有「搜尋」「離線」文字入口。
- 新訪客預設全台；記住使用者縣市偏好，分別標明全庫和目前範圍的收錄量。
- 函釋筆數使用獨立統計檔，點開時才下載該法規摘要；失敗可重試。
- 正式法規名稱加條號可連到已收錄條文；能核實的項款可精確定位。未核實或歧義引用保留文字。
- 每部法規生成 `/laws/<法規ID>.html` 獨立頁，提供原文、標題、canonical、sitemap。舊 `#law=` 分享網址保留相容。
- 「資料與開源 → 收錄清單」可查看各地全文、連結、擷取日期及議題缺口；議題分類不代表收錄完整或案件適用。

## 資料與離線

中央 XML 快照沿用 **2026-09-18**；新增地方頁面於 **2026-09-28** 擷取。既有 353 部全文快照保持不變。國土署函釋仍為原有 **9,054 筆**（9,012 筆本文、42 筆僅主旨／字號），未重新下載函釋來源；依新法規目錄重建後有 **7,923 筆明示條號關聯**。

法規逐部分片、函釋依固定 ID 區間分片，以 SHA-256 定址。搜尋使用 CJK 倒排索引找候選，再以原文驗證。可按中央、縣市及函釋選擇離線包，不強迫首次下載全庫。

schema v2 保留官方文字、穩定條文 ID、可確認的項款範圍及觀測紀錄。地方段落無法核實項款時保留原文，不推測結構。觀測日期不等於修正或生效日期。

## 開發與部署

Node.js 24（最低 22.13）、npm；資料同步另需 Python 3.12 與 lxml。

```sh
npm ci
npm run dev
npm run build
npm run typecheck
npm run check
python3 scripts/validate-data.py
```

資料維護後執行 `npm run snapshot`，再重新建置。`--add-only` 可只補地方資料並保留已有全文；完整同步沿用每週草稿 PR 流程。

用 GitHub Desktop 提交完整原始專案，Vercel 執行 `npm run build`，輸出 `dist`。原始碼包與部署包內容相同、擇一使用；不受 100 檔限制，生成的分片及靜態頁不需手動提交。詳見 [DEPLOY.md](DEPLOY.md)。

單檔 `openlawtw.html` 已內嵌全部收錄資料，可直接開啟。PWA 需 HTTPS 或 localhost；官方附件和外部網址仍需網路。

## 範圍與開源

這仍不是全台所有建築法規的完整集合，也不判斷案件適用或函釋效力。基隆、宜蘭、花蓮、嘉義市、嘉義縣及雲林的來源本次未能取得全文，已保留缺口。程式及資料包已更新；尚未部署 Vercel 或在遠端啟用排程。

別名與查找詞彙分別放在 `data/aliases.json`、`data/search-vocabulary.json`，可直接用 PR 補充；建置同時輸出引線共用資料。已附 PR 驗證及每週同步草稿 PR，維護者覆核後合併。

`SCHEMA.md` 說明資料結構；`CONTRIBUTING.md` 說明貢獻；`VALIDATION.md` 記錄驗證界線。程式 MIT 不覆蓋資料及第三方授權，見 `DATA_LICENSE.md` 與 `THIRD_PARTY_NOTICES.md`。
