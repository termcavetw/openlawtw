## 轉製內容與驗證

內容包含 10 章、4 個參考附錄、70 節，以及原 PDF 的封面與目錄，共覆蓋 105 個實體頁面。本文 942 行原生文字依來源順序保留，僅合併實體頁面造成的段落換行。頁碼欄位均指 PDF 實體頁碼；本文印刷頁碼比實體頁碼少 7。

134 個原始嵌入圖像轉成 131 個裁圖；其中原本同列並排的圖像合併為一張，以保留相對位置。另有 1 個原生線條表格裁圖、7 張封面與目錄裁圖，合計 139 個 WebP。裁圖由 PDF 原位置直接渲染，使用無損壓縮，沒有重繪、OCR、更動圖中文字或推估尺寸。原始圖片本身的模糊程度仍保留；放大不會增加原始資訊。

`sourceLines` 保存每節原生文字；`searchText` 供查找；`blocks` 供閱讀。文字段落的 `page` 與 `endPage` 可跨頁。圖片的 `sourceRect` 使用 PDF 頁面左上角座標（point），`sourceImages` 對應該頁原始影像的零起算索引。若圖號位於下一頁，`captionPage` 保留該頁碼。標題、正文、圖說、表格文字的排列均依原 PDF，不自行修正原文可能存在的誤植。

重新產生或驗證（需安裝 `pdfplumber`、`pypdfium2`、`Pillow`；一般網站建置不需要 Python）：

```text
python scripts/import-accessibility-reader.py
python scripts/import-accessibility-reader.py --check
```

驗證涵蓋原 PDF SHA-256、每個圖檔 SHA-256 與尺寸、本文逐行順序、全部 134 個原始影像、105 頁涵蓋範圍、章節起始頁，以及跨頁段落和純圖片頁的回歸案例。來源 PDF 若改版，匯入器會停止，需先人工核對版次及版面後更新。

參考附錄的性質依原文第 105 節：提供設計者參考，具指導性質，非屬強制性規定。
